\section{Snapshot 1: Start}
At the start we just tried to figure out what we were building and get everything set up. We picked the Public Defender Office project and started setting up GitHub, writing the first drafts of the SDD and SRS, and figuring out what tools we needed like SharePoint, React, TypeScript, and Azure AD.

\section{Snapshot 2: Checkpoint 1}
By this point we had the base stuff done and started working on the actual features. We focused on making sure users only see content for their role. We ran some test cases in TestRail to make sure the role filtering was actually working and updated the documents to match what we built.

\section{Snapshot 3: Checkpoint 2}
We kept adding features in this phase. We worked on the Office Hoteling System so staff can reserve desks, the Attorney Workload Dashboard, and the Expert Witness Directory. We added more TestRail test cases for these and kept updating the SDD and SRS.

\section{Snapshot 4: Final}
This was mostly cleanup and getting everything ready to turn in. We went through the documents, made sure the repo was organized, and wrapped things up. If we had more time we would have added mobile support, some kind of AI recommendation feature, and better analytics.
