\section{Snapshot 1: Start}
The goal at the start was to plan out the project and set up the foundation. We decided on building a role-based intranet for the Santa Barbara County Public Defender's Office. We set up the GitHub repo, created the basic documents, and outlined what the system needed to do. We also identified the tools we would use: SharePoint, React, TypeScript, and Azure AD.

\section{Snapshot 2: Checkpoint 1}
We reflected on what was set up in Snapshot 1 and began building out the core features. The main focus was role-based access control, making sure each user only sees content meant for their role. We added test cases in TestRail to verify that the role filtering was working correctly. Documents like the SDD and SRS were updated to reflect the new work.

\section{Snapshot 3: Checkpoint 2}
We reflected on the role-based access work from Snapshot 2 and added more features. This phase focused on the Office Hoteling System, the Attorney Workload Dashboard, and the Expert Witness Directory. More test cases were added in TestRail to cover these new features. The SDD, SRS, and Design Spec were updated with the new information.

\section{Snapshot 4: Final}
We wrapped up the project and added finishing touches. Everything was reviewed and cleaned up for final submission. Documents were finalized and the GitHub repo was organized. Future work ideas include mobile optimization, AI-based resource recommendations, and better analytics dashboards.
