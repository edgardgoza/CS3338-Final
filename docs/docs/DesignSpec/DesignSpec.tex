\section{Overview}
This document goes over every page and feature of the PD-Intranet project. It also lists all the packages and libraries needed to get it running in Docker.

\section{Pages and Components}

\subsection{Login / Authentication}
Users log in through Azure Active Directory. Once they are in, the system figures out their role and sends them to the right dashboard.

\subsection{Role-Based Dashboard}
This is the home page every user sees when they log in. What shows up depends on their role. We have 9 roles total: Attorney, Paralegal, Investigator, Social Worker, Admin Staff, IT, Management, Public Defender, and Intern.

\subsection{Office Hoteling System}
Allows staff to reserve desks in advance. Displays real-time desk availability per office location.

\subsection{Attorney Workload Dashboard}
Displays active case counts, upcoming deadlines, and workload summaries for attorneys and supervisors.

\subsection{Urgency Portal}
Powered by PowerBI. Displays analytics on high-priority cases and flagged items for management review.

\subsection{Expert Witness Directory}
A searchable directory of expert witnesses, filterable by specialty and availability.

\subsection{Resource Libraries}
Role-scoped document libraries. Staff only see folders and files relevant to their department.

\subsection{Announcements}
Office-wide and role-targeted announcements managed by admins.

\section{Docker Container Setup}
To run the development environment in Docker, the container requires:
\begin{itemize}
    \item Base image: \texttt{node:18}
    \item Install global tools: \texttt{npm install -g gulp-cli @microsoft/generator-sharepoint yo}
    \item Copy project files and run \texttt{npm install}
    \item Expose port \texttt{4321} for the local SharePoint workbench
    \item Build with \texttt{gulp bundle} and package with \texttt{gulp package-solution}
\end{itemize}
