# Docker Notes

This project is based on SharePoint Framework, so real production deployment depends on Microsoft 365, SharePoint App Catalog, Azure Entra ID, Microsoft Graph API, and Power BI.

The Docker setup is a planning/template setup:
- frontend-dev: placeholder SPFx/Node environment.
- mock-api: placeholder backend/API simulation.
- mock-db: optional PostgreSQL testing database.

Run:
```bash
docker compose up --build
```
